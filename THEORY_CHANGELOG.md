# OAP Theory Change Note

The v0.1 experiment keeps its existing `context_openness` and `investigative_autonomy` runtime switches, but their theoretical status has changed.

They are now treated as the first operationalization `Ψ₀` of the OAP polity semantics:

- authoritarianism ↔ egalitarianism
- exclusionism ↔ pro-external openness

The four runtime behaviors (passive tool / informed adviser / blind investigator / open evidence partner) are experimental phenotypes, not definitions of the four polity quadrants.

Therefore the current DeepSeek + Seed attractor experiment remains valid. It tests whether this particular operationalization is useful; it does not establish that C/I are the permanent ontology of OAP.

See `THEORY.md` for the updated three-layer model:

`Polity Semantics → Operationalization → Emergent Phenotype`.
